行棋规则

帥 / 將

每着沿直线走一步，不出九宫。双方将帅不可在同一纵线直接照面（飞将）。

仕 / 士

每着沿斜线走一步，限在九宫内，全程五个落脚点。

相 / 象

走「田」字对角，不可过河；田心有子则塞象眼，不能走。

傌 / 馬

走「日」字，先直后斜；直行方向有子挡住马腿则不能走。

俥 / 車

沿直线任意步数，遇子止步，可吃对方棋子。

炮 / 砲

不吃子时同车；吃子必须隔一个棋子（炮架）打对方的子。

兵 / 卒

只能向前走一步；过河后可左右各一步，永不后退。

胜负与和棋

将死或困毙对方者胜；六十回合无吃子判和；局面三次重复判和，长将判负；双方均无车马炮兵判和。
