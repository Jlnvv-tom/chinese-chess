# 楚河漢界 · 3D 中国象棋

一款具有强烈视觉冲击力的创意 3D 中国象棋游戏。完整实现全部标准规则，沉浸式 3D 场景、
动态光影、流畅交互，以及独特造型的棋子艺术。

## 快速开始

**方式一：单文件版（推荐，无需服务器）**

直接用浏览器打开 `dist/chinese-chess-3d.html`（约 700KB，three.js 已内联，完全离线可用）。

**方式二：开发版（本地服务器）**

```bash
cd chinese-chess
python3 -m http.server 8765
# 浏览器访问 http://localhost:8765
```

## 玩法

- 点击棋子 → 显示可走位置（绿点）与可吃目标（橙环）；再次点击目标落子
- 拖动旋转视角 · 滚轮缩放 · 右键（或 Shift+拖动）平移
- 人机对战（初学/棋友/国手三档 AI）或双人对战；可选择执方
- 支持悔棋、翻转视角、复位视角、音效开关、规则说明

## 规则实现

完整标准规则，经 perft 权威数值校验（初始局面 44 / 1920 / 79666，与 Chess Programming
Wiki 参考值一致）：

| 模块 | 内容 |
| --- | --- |
| 走法与吃子 | 车/马/炮/象/士/将/兵 全部走法；蹩马腿、塞象眼、炮翻山吃子、象不过河、将士不出九宫、兵过河横走 |
| 将军与将死 | 将军判定、将死（杀棋）、困毙（无着可走亦判负）、飞将（将帅照面） |
| 和棋 | 六十回合无吃子自然限着、局面三次重复判和、双方无车马炮兵例和 |
| 长将 | 三次重复且由一方连续照将 → 长将方判负 |
| 记谱 | 标准中文记谱（炮二平五、马8进7、前车九进一…），红方汉字、黑方阿拉伯数字 |

## 棋子造型设计

每种棋子均为独立设计的非扁平造型，强调角色特征：

- **帥/將（统帅）**：车削甲胄躯干 + 环座六棘王冠 + 护心镜 + 顶珠
- **仕/士（谋士）**：修长身躯 + 前倾乌纱帽 + 帽正宝石
- **相/象（大象）**：圆穹身躯 + 招风大耳 + 两段弯鼻 + 金獠牙
- **傌/馬（战马）**：马首侧影浮雕（锐耳、鬃毛棘、金鬃线），马头转向玩家
- **俥/車（战车）**：方塔 + 雉堞 + 金顶 + 背帜 + 双轮
- **炮/砲（大炮）**：炮车 + 仰角炮管 + 双加强环 + 炮口（吃子时有后座动画）
- **兵/卒（小卒）**：圆躯 + 碗盔 + 盔缨

红方朱漆金字、黑方乌木金字，统一的车削底座形成家族感。

## 技术要点

- Three.js r149 UMD 版（本地化，无 CDN 依赖）；经典 script 加载，`file://` 可直接运行
- 程序化贴图：木纹年轮、金漆字牌、光晕精灵、背景穹顶、河界文字，全部 Canvas 生成
- 动态光影：主聚光灯缓慢环绕产生移动投影、冷色轮廓光呼吸、将军红光脉冲、选中跟随光
- 氛围：萤火粒子、上升光尘、体积光束、远山剪影、指数雾
- 动画：补间系统（马跳跃抛物、炮后座、吃子倾倒滑落、火花迸溅、相机补间翻转）
- AI：迭代加深 Alpha-Beta + 吃子静态搜索 + MVV-LVA 排序 + 时间预算（≤2.2s）
